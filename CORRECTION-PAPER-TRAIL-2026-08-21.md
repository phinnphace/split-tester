# Paper Trail corpus correction

**Correction identified:** 16 August 2026  
**Full active-data purge completed:** 21 August 2026

The reference document *Tortured Phrases: A Dubious Writing Style Emerging in Science* was mistakenly included in the initial Paper Trail corpus. It was not one of the citation records intended for review.

The reference document was first removed and affected analyses were rerun. Because later cataloging, grouping, visualization, and public outputs still descended from the original master input, the project subsequently retired the entire active corpus and its derivatives. The rebuild will begin from a corrected master citation CSV.

The purge covered the active source collection, extracted text, databases and backups, evidence records, cluster assignments, node-map data, summaries, analysis exports, correspondence derivatives, reproducibility derivatives, and public browser data. The public catalog and map routes now carry only the correction and rebuild status.

The generic catalog schema and review protocol were retained. No paper record or analytical result from the retired corpus will be copied into the clean rebuild.

The repository's Git history has not been rewritten. Earlier commits remain available as the record of the original publication and subsequent correction.

## Rebuild publication

On 27 August 2026, the corrected corpus and its first-iteration relationship map were
published. The obsolete correction-only pause page was removed from the current build because
it no longer represented the project's active state. The correction, the pause, and the prior
build remain documented in this record and in ordinary Git history.
